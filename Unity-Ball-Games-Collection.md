# Unity Open Source Ball Games Collection

This document compiles open-source Unity ball game projects from GitHub, with a special focus on motion sensing and gesture-controlled games.

These games use Kinect or other motion sensing devices for interaction, perfect for gesture-based gaming.

## 📝 Usage Recommendations

1. **If you have Kinect v2**: Try Kinect-Unity-Basketball or Tennis project
2. **If you have PlayStation Move**: Try Basketball Game (PSMove)
3. **If you have VR device (HTC Vive, etc.)**: Try VRTK.Tutorials.VRBowling
4. **If you want to learn game development**: Try 08-Bowlmaster-Original (TDD) or BasketballFreeThrowUnity (tutorial)
5. **If you want to develop mobile games**: Try Ball-Fall-game-Unity2D or swish-shot
